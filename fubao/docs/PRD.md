# PRD – Fubao Beauty Centre web app (v1)

**Goal:** let customers see services/prices, buy packages, book appointments and track what is used/left; let the owner run everything from one portal.
**Users:** Customer · Owner · Beautician. **Language:** English. **Location:** 28, Jalan Perdana 1/4, Ampang (studio); home service around Klang Valley, +RM30/visit.

| # | Requirement | Status |
|---|---|---|
| 1 | Services with photos, price before/after; packages with validity counted from purchase | Done |
| 2 | Vouchers for all or specific customers | Done |
| 3 | Flash promotions with countdown, shown on login | Done |
| 4 | Session duration + gap per service for booking spacing | Done |
| 5 | Calendar availability; customers book in free slots | Done |
| 6 | Multi-beautician: skills, working hours, assignment, no overlap | Done |
| 7 | Studio and/or home service (+RM30), per-service control, area list | Done |
| 8 | Customer sees catalogue, purchase history, used/left/validity | Done |
| 9 | Name/contact/address for home visits; deposit % setting; receipt upload | Done (deposit off by default) |
| 10 | Vouchers and points (RM100 = 1 pt = RM1) | Done |
| 11 | Daily mini-game, +0.01 point, once a day | Done |

**v1.1 additions:** email alerts via free SMTP; forgot-password for all accounts; per-customer birthday/referral rewards set by owner.
**Out of scope:** online payment gateway, SMS/WhatsApp alerts, multi-branch.
**Owner-configurable (backend):** opening hours, package validity, session length, studio/home per service, cancellation notice (default 24h).
